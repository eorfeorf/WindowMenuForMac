# Window Menu v0.2.0

Window Menu 0.2.0 combines per-window menu bars with a single app launcher in the macOS menu bar.

- Universal app for Intel and Apple Silicon Macs; requires macOS 13 or later.
- Includes a searchable launcher, Dock app import, and recoverable Dock auto-hide setting.
- Accessibility permission is required for reading and operating other apps' window menus.

## Install

Open the DMG and drag `Window Menu.app` to Applications. Follow the included Japanese installation guide. Because this build is not signed and notarized with an Apple Developer ID, macOS may require Control-click > Open on first launch.

No open-source license has been selected for the source code.
